1.1 Ingreso a la banca empresas con usuario y contraseña

8 SP #/login
Descripción

Como usuario registrado de la empresa,

Quiero ingresar a la banca web con mi usuario y contraseña

Para acceder de forma segura a los productos y operaciones de mi empresa.

Criterios de aceptación
  1. Dado que estoy en la pantalla de ingreso, cuando ingreso un usuario y una contraseña válidos y presiono «Ingresar», entonces el sistema me autentica y me presenta el Inicio.
  2. Dado que dejo el usuario o la contraseña vacíos, cuando presiono «Ingresar», entonces el sistema marca el campo faltante en estado de error y no envía el formulario.
  3. Dado que las credenciales son incorrectas, cuando presiono «Ingresar», entonces el sistema muestra un mensaje de error claro sin revelar cuál de los dos datos es inválido.
  4. Dado que no tengo usuario, cuando visualizo la pantalla, entonces veo el enlace «Crea tu usuario aquí» que me lleva a la creación de usuario.
  5. El botón «Ingresar» muestra estado de carga mientras se valida y se deshabilita para evitar doble envío.
Definition of ReadyDiseño de la pantalla de ingreso aprobado; servicio de autenticación disponible.
Definition of DoneCumplimiento de los criterios de aceptación.
ServicesConsume el servicio core de autenticación de usuario empresas.
TagsC1: Accesos y Seguridades login
Value AreaBusiness
